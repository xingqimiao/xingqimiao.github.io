# 隐私与数据处理说明

更新日期：2026-06-05

KiraMyao Equal 是一个以跨性别群体处境、故事、资料整理与公共倡议为核心的静态信息网站。问卷只是网站的一部分，我们也会发布报告、项目故事、文章、投稿内容以及公开资料整理。

这份说明希望把网站本身、问卷收集、投稿与公开资料整理放在同一个清晰的隐私框架里：我们会尽量少收集信息，尽量少保留可识别内容，并把任何涉及个人经历的数据放在更谨慎的位置处理。

## 1. 网站托管、DNS 与访问分析

KiraMyao Equal 当前是一个静态网站，页面内容经过静态导出后托管在 Cloudflare Pages 上，并由 GitHub 作为源码仓库与版本管理平台。静态网站本身不会运行我们自建的后端数据库，也不会在你浏览页面时主动创建账号系统或站内登录记录。

网站域名通过 Cloudflare DNS 进行解析。为了了解网站访问量、页面浏览趋势与基础访问情况，我们使用 Cloudflare Web Analytics 进行网站流量分析。

网站访问始终使用 HTTPS 协议，并基于 SSL/TLS 证书建立加密连接；在可用环境下，站点启用 TLS 1.3 协议，以降低传输过程中被窃听、篡改或劫持的风险。传输加密保护的是你与网站之间的数据传输过程，并不意味着任何第三方表单平台或基础设施日志完全不存在，因此我们仍然坚持最小化收集和谨慎处理原则。

Cloudflare Web Analytics 主要帮助我们理解：

- 哪些页面被访问得更多
- 网站在不同时间段的大致访问趋势
- 页面加载与访问来源的大致情况
- 内容是否真的被读者看见

我们使用这类统计的目的，是为了改进网站内容组织和公共传播效果，而不是识别、追踪或画像具体个人。

同时，Cloudflare 与 GitHub 作为网站基础服务与源码托管提供方，可能会在其基础设施层面处理必要的网络访问日志或版本管理记录，例如请求时间、IP 地址、浏览器信息、访问 URL、提交记录或部署日志等。这些记录由对应平台按照其自身政策处理，并不由 KiraMyao Equal 用来建立个人档案。

## 2. 我们会主动接收或整理哪些信息

除了基础的网站访问统计外，我们主动接收或整理的信息主要来自：

- 你自愿填写的问卷调查
- 你主动提交的投稿、故事或联系内容
- 我们在研究和资料整理过程中看到的互联网公开信息
- 为报告、文章或公共倡议所需而进行的人工整理与归纳

我们不会因为你只是访问网站，就要求你提供姓名、手机号、证件号、住址或其他强身份信息。

如果某些问卷或投稿确实涉及敏感经历，我们会在具体表单或页面中尽量说明用途，并只在完成相关整理所必需的范围内使用。

## 3. 关于 Google Forms 与腾讯问卷平台

网站中的部分问卷会通过 Google Forms 或腾讯问卷等第三方表单平台承载。它们是问卷提交工具，不代表网站整体只有问卷功能。

当你填写这些问卷时，问卷平台可能会按照其自身服务规则处理必要的提交数据与访问数据。你在填写前可以自行判断是否接受对应平台的服务环境。

我们在问卷设计与数据使用上会尽量遵循：

- 不要求无关的强身份信息
- 不把敏感问题设计成强迫暴露
- 不将单份问卷内容直接公开展示
- 不将问卷原始数据交给无关第三方
- 不把问卷数据用于商业广告、用户画像或定向营销

问卷收集到的信息，只会围绕研究、报告、资料整理、公共倡议和必要的联系确认使用。

## 4. 问卷数据的本地化处理

对于包含个人经历、生活处境或敏感信息的问卷内容，我们会采用更谨慎的数据处理方式。

在初步整理、筛选、归档和分析阶段，问卷数据会尽量下载到受控的本地计算设备中处理，并减少不必要的云端流转。

我们不会在未经必要判断和处理前，把原始问卷内容随意分享给无关人员，也不会把它上传到不必要的协作平台中进行扩散式处理。

## 5. 去标识化与最小可识别原则

在发布报告、文章、统计结论或公开资料时，我们会优先进行去标识化处理。

这意味着我们会尽量：

- 删除或模糊姓名、联系方式等直接识别信息
- 避免保留过于具体的学校、单位、住址等线索
- 避免把多个细节组合成可反向识别某个人的内容
- 在引用个体经历时，只保留理解议题所必需的表达
- 对特别敏感或罕见的个案进行额外保护

我们希望读者能看见真实处境，而不是让任何一个具体的人因为发声而承担额外风险。

## 6. 新旧版本数据如何处理

如果问卷、文章或报告经历版本更新，我们可能会保留旧版本数据用于对照、审校或历史归档。

但旧版本数据不会因此变成可以无限扩散、随意共享或脱离原始用途使用的材料。

对于旧版本问卷或历史资料，我们仍会遵守：

- 不公开原始敏感数据
- 不主动扩大可识别范围
- 不把历史数据用于无关目的
- 不因为版本更新而降低保护标准
- 在必要时对旧数据进行再清理
- 对已经不适合继续保存的材料进行删除或脱敏

如果某些旧内容需要转化为公开文章或故事，我们会在公开前重新评估其风险。

## 7. 投稿与故事内容

如果你主动向我们投稿，或授权我们整理、发布你的 Story，我们会把这类内容视为需要额外尊重的表达。

除非你明确同意，否则我们不会把你的私人经历直接作为可识别故事公开。即使获得授权，我们也会尽量与你确认：

- 是否署名
- 使用真实姓名还是化名
- 哪些细节可以保留
- 哪些信息必须删去
- 是否允许后续修改或撤回

故事的价值在于让更多人理解真实处境，而不是把讲述者推到风险前面。

## 8. 伦理审查声明

目前 KiraMyao Equal 的相关整理和问卷工作主要服务于公益表达、公共资料整理、处境观察和倡议传播。

除非另有明确说明，本网站内容不等同于经过机构伦理审查委员会（IRB）批准的正式学术研究项目。

因此我们会主动避免：

- 以学术研究名义要求你提供过度信息
- 将问卷结果包装成超出样本能力的绝对结论
- 使用可能造成伤害的诱导式问题
- 在没有充分保护的情况下展示高度敏感的个人经历
- 把公益调查变成对群体的凝视、消费或标签化

## 9. 我们不会做的事

我们不会：

- 出售你的个人信息
- 将问卷原始数据开放给无关第三方
- 为广告投放建立个人画像
- 因访问网站而要求你注册账号
- 在公开页面展示未经处理的敏感问卷内容
- 把你主动分享的经历挪作无关用途

## 10. 退出、删除与联系

如果你曾经提交过问卷、投稿或故事授权，并希望删除、修改或撤回相关内容，可以通过网站公布的联系方式联系我们。

由于部分问卷可能不要求填写姓名或联系方式，我们不一定能在匿名数据中准确定位某一份提交。若你希望未来能够撤回或修改内容，请在提交时保留足够用于识别该份提交的自定义线索。

对于已经进入公开报告、文章或传播材料的内容，我们会尽量在合理范围内处理你的请求，并优先考虑你的安全和意愿。

## 11. 最后的承诺

我们希望这个网站既能被看见，也不会让任何一个愿意信任我们的人被迫暴露。

KiraMyao Equal 会持续在表达、研究、传播与保护之间寻找更负责任的平衡。

在这里，你可以安心地发出声音，也可以安全地隐匿于星海。
